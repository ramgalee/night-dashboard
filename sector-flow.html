오실레이터 = 업종에 속한 종목들의 (외국인+기관 5일 누적 순매수 ÷ 시가총액)으로 MACD(12·26)를 구하고 시그널(9)을 뺀 값. 0 위면 수급이 들어오는 쪽으로 빨라지는 중, 0 아래면 빠지는 쪽입니다. 숫자가 아주 작아 1만을 곱해 보여 줍니다.
상태 — 양수 전환 0 아래에서 위로 올라선 첫날 · 양수에서 상승 · 양수이나 둔화 · 음수에서 반등 · 음수 전환 0 위에서 아래로 내려선 첫날 · 내림세. 옆의 숫자는 0 위(또는 아래)에 며칠째 있는지입니다.
외인+기관 오늘 · 5일 누적은 억원. 업종 지수는 시총가중으로 120일 전을 100으로 둔 것입니다.
업종 이름을 누르면 120일 지수·오실레이터와, WI26·테마는 시총 큰 종목이 나옵니다. 종목을 누르면 수급오실레이터 페이지로 갑니다.
